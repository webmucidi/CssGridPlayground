CSS Grid

Sayfayı iki boyutlu parselleyen ızgara sistemi.

Enine ve boyuna grid çizgileriyle ızgara şeklinde bölümlendirir. Hücreler, sütun çizgilerinin oluşturduğu sütunlar (grid-column) ile satır çizgilerinin oluşturduğu satırların (grid-row) kesişiminde oluşur. Masaüstü layout tasarımları genel olarak 12 sütunlu yapılar kullanır.

header
sidebar
main
footer
.demo {
  display: grid;
  grid-template-columns: 1fr 2fr 2fr;
  grid-template-areas:
    "h h h"
    "s m m"
    "f f f";
  gap: 8px;
}
.m { grid-area: m; }

Kapsayıcı özellikleri

display: grid;
Nesnelerin görünüm ve yerleşim modunu grid olarak ayarlar.
grid-template-columns: 100px 1fr 2fr 4fr;
Grid içinde 4 adet sütun tanımlar.
grid-template-rows: repeat(4,auto);
Grid içinde 4 adet satır tanımlar.
grid-template-areas: "header header header";
Grid içinde sözel olarak alanları haritalar.
gap: 10px;
Grid hücreleri arasında boşluk oluşturur.

Çocuk nesne özellikleri

grid-column: 1/5;
Sütunun başlangıç ve bitiş çizgisini belirler.
grid-row: 1/ span 2;
Satırın başlangıç çizgisini ve satır birleştirme miktarını belirler.
grid-area: ustAlan;
Sayfa haritalamasındaki yerleşimi için çocuk nesneyi etiketler.

Akılda kalsın

fr birimi: Grid sistemine özel, orantısal birimdir. Sütun ve satır boyutlarını kapsayıcıya endeksli olarak dağıtır. Sayısal birimler (px, %) de kullanılabilir.
repeat: Aynı ölçüde birden fazla sütun veya satır oluşturmak için kullanılır.
grid-template-areas: Layout tasarımlarında alanların yerleşimi için genelde sözel haritalama (yerleşim planı) yapılır.
Sıralama: DOM akışında ilk sırada olan nesne ilk sırada görünmek zorunda değildir. grid-column, grid-row ve grid-area değerleri sıralamayı belirler.
